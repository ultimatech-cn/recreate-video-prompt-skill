# 视频复刻提示词智能体 Skill

这是一个与厂商无关的多模态智能体Skill，用于分析参考视频、人物身份图片和可选补充需求，并生成稳定的AI视频生成提示词。

它不依赖GPT、OpenAI、ComfyUI或特定视频模型。只要智能体能够查看视频和图片，或者能够读取上游提供的可靠视频分析，就可以使用。

## 三种接入方式

1. **原生Skill加载**：将整个目录放入智能体框架配置的Skills目录，入口为`SKILL.md`。
2. **系统提示词加载**：把`prompts/agent-system-prompt.md`作为系统指令或开发者指令。
3. **Agent/API调用**：使用`schemas/input.schema.json`组织输入，使用`schemas/output.schema.json`验证输出。

## 输入职责

- 参考视频：负责动作顺序、时间节奏、接触关系、物体轨迹、镜头和情绪节奏。
- 人物图片：负责替换人物的身份、面部、发型、肤色和体型。
- 补充需求：优先级最高，可以为空。
- 生成提示词：只负责把以上信息组织成视频模型能理解的导演指令。

## 重要限制

这个Skill生成的是语义提示词，不是动作迁移。如果目标视频模型支持V2V、Motion Reference、Pose、Depth或Camera Control，还应该把参考视频或提取的动作控制直接传给视频模型。

纯文本智能体不能假装看过无法访问的视频。此时必须提供按时间排列的关键帧、时长、镜头运动、动作顺序、接触关系和物体轨迹分析。
